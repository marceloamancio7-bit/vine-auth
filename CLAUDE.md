# vine-auth

## Regras de trabalho (herdadas das preferências globais do dono)
- EXECUTE FIRST — pergunte só se estritamente necessário (credenciais, decisões comerciais, ações destrutivas/irreversíveis, produção/custos/pagamentos/dados reais). Consolide dúvidas em uma mensagem.
- Economia de tokens: leia só o relevante, busca direcionada, logs filtrados, respostas objetivas.
- Preserve APIs, auth, permissões, banco, DNS e config de produção. Nunca exponha segredos. Não declare sucesso sem evidência de execução.
- Resposta final: Concluído / Validado / Pendências / Próximo passo (só se relevante).

## Projeto
- Biblioteca TypeScript. Validação: `npm run typecheck` e `npm run build`.
